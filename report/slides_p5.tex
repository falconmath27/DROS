\begin{frame}{Uncertainty, costs and limits}
\begin{itemize}
\item Paired 30-day date-block bootstrap; 15/60-day sensitivity; Holm within comparison families.
\item Utility and economic returns labelled separately. Cost sweeps refit policies.
\item Calendar slices: 2020, 2022, other years; no 2008 coverage.
\item Deadline purge, prefix-causality and terminal checks; stylized close fills.
\item Fixed universe selection bias; overlapping windows are not portfolio returns.
\item Optional stopping does not guarantee profits; concave utility changes the optimization target.
\item Volatility-persistence plot exploratory; Hurst and regime diagnostics not completed.
\end{itemize}
